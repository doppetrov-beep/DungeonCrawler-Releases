# DungeonCrawler — скачать игру

**Готовые сборки игры для Windows 10/11 x64.** Это публичный репозиторий **только для распространения готовых сборок**: архивы ZIP, контрольные суммы, заметки об изменениях и инструкции. Исходный код находится в отдельном закрытом репозитории и сюда не переносится.

## Скачать

- **[Все выпуски DungeonCrawler](https://github.com/doppetrov-beep/DungeonCrawler-Releases/releases)** — здесь находятся тестовые и стабильные версии.
- **[Последняя стабильная версия](https://github.com/doppetrov-beep/DungeonCrawler-Releases/releases/latest)** — ссылка заработает после публикации первого стабильного релиза.

> **Пока релизов нет.** Не скачивайте `Source code (zip)` или `Source code (tar.gz)`: это автоматически созданные GitHub архивы файлов **этого** репозитория, **не игра**. Для запуска нужна прикреплённая к выпуску **полная сборка Windows10/11 x64**.

### Стабильная версия или тестовая?

| Обозначение на GitHub | Для кого | Что ожидать |
| --- | --- | --- |
| **Latest / Stable** | Для обычной игры | Выпуск после автоматических проверок и игровой приёмки |
| **Pre-release / Тестовая** | Для добровольного тестирования | Новые изменения; возможны ошибки, совместимость с сохранениями уточняйте в описании |
| **Draft** | Не опубликовано | Не доступен для скачивания игрокам |

Тестовые сборки публикуются **только как Pre-release**, не назначаются «Latest» и не заменяют стабильную версию. Все предыдущие опубликованные выпуски остаются доступными в списке Releases.

## Установка на Windows 10/11 (64-bit)

1. Откройте [Releases](https://github.com/doppetrov-beep/DungeonCrawler-Releases/releases) и выберите нужный выпуск. Если хотите только стабильный, используйте ссылку «Последняя стабильная версия» выше.
2. В разделе **Assets** скачайте **полный игровой ZIP для Windows10/11 x64**, а не архив исходников GitHub. Рядом может быть файл `SHA256SUMS.txt` для сверки контрольной суммы.
3. Распакуйте ZIP **целиком** в новую папку, например `C:\Games\DungeonCrawler\`. Не запускайте игру прямо внутри ZIP и не копируйте новую версию поверх прежней.
4. В распакованной папке запустите **`Start_Game.cmd`** (или `dungeon.exe`, если указано в инструкции конкретного выпуска). **Git, компилятор и установка исходников не нужны.**
5. Для HTML-окон может потребоваться бесплатный **Microsoft Edge WebView2 Runtime (Evergreen)**, если он не установлен на компьютере: [официальная загрузка Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).

В полном ZIP должны присутствовать `dungeon.exe`, `Start_Game.cmd`, папки `Assets/`, `ThirdParty/`, `Config/`, а также `README_RU.txt` и/или заметки об обновлении. Если этих файлов нет — архив неполный: сообщите разработчику, не используйте его как готовую сборку.

### Проверка скачанного архива (необязательно)

Если к выпуску приложен `SHA256SUMS.txt`, сравните хеш скачанного ZIP с опубликованной суммой. В PowerShell в каталоге загрузок выполните:

```powershell
Get-FileHash -Algorithm SHA256 ".\ИМЯ_СКАЧАННОГО_АРХИВА.zip"
```

Значение `Hash` должно совпасть с SHA-256, указанной у этого файла.

## Обновление и сохранения

**Перед переходом на новую версию сделайте резервную копию сохранений.** Их расположение может отличаться по версиям: `saves\` рядом с прежним EXE или `%LOCALAPPDATA%\DungeonCrawler\Saves\`. Не удаляйте старую папку игры до проверки загрузки сохранений.

Новую версию распаковывайте **в отдельную папку**. Сведения о совместимости сохранений, изменениях и необходимом переносе смотрите **в описании соответствующего Release** и в инструкции внутри ZIP. Не заменяйте существующие файлы сохранений без резервной копии.

## Проблемы и обратная связь

При ошибке, **если игра продолжает отвечать**, нажмите **F9**, чтобы запросить диагностический отчёт, и передайте его разработчику. Фактическую папку отчётов и способ передачи смотрите в инструкции именно вашей сборки. При полном зависании F9 может не сработать. Перед отправкой проверьте содержимое архива диагностики: он может включать персональные данные, в том числе сохранения.

Для отчёта об ошибке полезно указать **номер версии**, шаги воспроизведения, Windows 10 или 11, скриншот и (если возможно) отчёт F9. Тестовые выпуски созданы именно для такой обратной связи.

## Для сопровождающих

Публикуйте в этом репозитории **только готовые ZIP и SHA256SUMS**, не исходный проект, ветки разработки или рабочие файлы. Каждый выпуск должен включать полный ZIP для Windows 10/11 x64, версию, краткие изменения, совместимость сохранений и инструкцию обновления. Проверки: чистая сборка, автоматические тесты, распаковка и целостность ZIP; ручную игровую проверку, если не проведена, отмечайте `NOT RUN`.

Первый подтверждённый тестовый выпуск: **Pre-release**, никогда не `Latest`. Стабильный выпуск — только после отдельной игровой приёмки владельцем.
